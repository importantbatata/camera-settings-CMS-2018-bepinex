# Camera Settings for Car Mechanic Simulator 2018

Version 1.3.0 · Windows · BepInEx 5 Mono

In the garage, press **Esc** and choose **Camera Settings**, directly above **Continue**.

- **Field of View** adjusts the main gameplay camera from 40° to 130°. Your setting carries across walking and repair views.
- **Look Sensitivity** adjusts walking and repair controls from 25% to 300%.
- **Reset Camera Settings** restores the game's FOV and 100% look sensitivity.

Drag a slider or select it and use the menu's left and right controls. Both settings are saved when you leave the page. Earlier FOV and sensitivity settings carry forward.

## Install

Close CMS 2018 and extract the ZIP into the folder containing cms2018.exe and BepInEx. The DLL belongs at BepInEx/plugins/CameraPresets/CameraPresets.dll. Use one copy of the plugin.

## Optional shortcuts

Use Left Alt + [ or ] to adjust sensitivity and Left Alt + 0 to reset it. BepInEx stores these shortcuts, FOV, sensitivity, and the notification preference in BepInEx/config/local.cms18.camerapresets.cfg.

Version 1.3.0 removes the saved view feature. Previously saved preset files can be reused with an older release.
